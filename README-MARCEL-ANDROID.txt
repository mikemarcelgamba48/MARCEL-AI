MARCEL Android starter project

Merge the contents of this folder into the root of your existing MARCEL-AI GitHub repository.
Do not delete the existing website files or app.js.

This creates a basic Android application shell. It does not yet contain a local language model,
working camera gesture recognition, or full offline AI. Those features require separate
implementation and testing.

GitHub Actions should use Java 17, Android SDK platform 35/build-tools 35.0.0,
and Gradle 8.9 to build the debug APK.
